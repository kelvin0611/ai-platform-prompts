## 三類 Prompt

| 類 | 幾時用 | 重點 |
|---|---|---|
| 🟦 **理解類** | **做之前** | 唔係叫佢做嘢，係叫佢講你知 |
| 🟩 **動手類** | 明白之後 | 講清楚「要有咩」「唔要咩」|
| 🟥 **保命類** | 出事 | 唔好重做，唔好亂撳 |

> ⚠️ **唔好跳過理解類。** 明白之後才動手，出事率低好多。

## 最值錢嗰條

```
我撳咗 <X>，出咗 <Y>，但我想要 <Z>。

先唔好改 code。先用 3 句講你估係咩原因，同埋你點知。
我確認之後你才改。
```

**叫 AI 先諗後改** —— 咁你就會知佢係唔係亂估。

## 五條鐵律

1. 一次只改一個位 —— 改完即刻跑一次
2. 唔明就問「點解」—— 唔好照 copy
3. 唔明就講「我睇唔明」—— 佢會翻譯成人話
4. 壞咗唔好重做 —— 講返「我撳咗 X 出咗 Y 我想要 Z」
5. 交嘢之前，自己先用一次 —— 冇試過唔算完成
