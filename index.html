📋 指令速查（導師／想自己打嘅人）

正常情況叫 AI 跑就得。呢啲係佢背後會用到嘅指令，睇一眼會明發生咩事。 

第一次（喺 project 資料夾入面）
  git init
  git add .
  git commit -m "first commit"
  git branch -M main
  git remote add origin <repo 網址>
  git push -u origin main

每次落堂
  git add .
  git commit -m "<一句英文>"
  git push

每次開課（新電腦）
  git clone <repo 網址>

每次開課（同一部電腦）
  git pull

三個名記住就夠：
add = 揀邊啲檔要儲存　·　commit = 打個記錄　·　push = 寄上 GitHub
